# Release checklist

Use this before publishing a new version of the playbook.

## Quality

- [ ] `npm run lint` passes.
- [ ] `npm run build` passes.
- [ ] The playbook route loads without console errors.
- [ ] External links open the intended PumpGTM or Instagram destination.

## Content

- [ ] Copy is specific, plainspoken, and written for the reader.
- [ ] Examples are clearly marked when they are hypothetical.
- [ ] Product references explain what PumpGTM does without promising an unverified action.
- [ ] Prompts require review before people are contacted or messages are sent.

## Responsive UI

- [ ] Navigation remains legible on desktop and mobile.
- [ ] The prompt modal fits within the viewport and can be closed with Escape.
- [ ] The start-play call to action has no heading or form overlap.
- [ ] Native-looking scrollbars and overflow are not introduced.
